# 公差計算ツール

ブラウザーだけで動作する、日本語の機械設計向け計算ツールです。サーバーや追加ライブラリは必要ありません。

## 使い方

- `index.html` をブラウザーで開くと、Web版を利用できます。
- `tolerance-tool-offline.html` を保存して開くと、広告なし・外部通信なしのオフライン版を利用できます。
- `nx-journal-generator.html` はNXジャーナル生成に機能を絞った単一HTMLです。公差計算や設定JSONの保存・読込機能を含みません。
- `index.html#simple` のように URL のハッシュを指定すると、各機能のタブを直接開けます。
- 計算例・使い方・FAQは、計算機の下にある解説セクションを参照してください。
- 計算式・規格の根拠と自己検証は「検証・根拠・履歴」タブを参照してください。

## NXジャーナルとセキュリティ

- オフライン版は外部通信をCSPで遮断し、外部ライブラリを読み込みません。入力値はジャーナル生成のためにブラウザー内で処理され、Webサーバーへ送信されません。
- NX専用版も外部通信をCSPで遮断し、外部依存・設定保存・設定読込を含みません。社内配布時は `SHA256SUMS.txt` のハッシュと照合してください。
- HTMLを開くだけではNXのモデルや社内ファイルを変更しません。生成したPythonジャーナルをNXで実行すると、現在のワークパートに板形状を作成します。
- ジャーナルは mm 単位の空パート向けです。既存ボディを検出すると形状作成を始めずに終了し、作成中のエラーはUndoマークまで戻します。
- 実行前に、ダウンロードしたPythonコードを全文確認し、社内のソフトウェア利用・ジャーナル実行ルールに従ってください。NXのバージョンや設定によって動作は異なる場合があります。

## 編集とビルド

公差計算機・NX生成UI・ジャーナル処理は `index.src.html`、NX専用版のページ枠・CSP・スタイルは `nx-journal-generator.template.html` を編集し、次のコマンドで配布用ファイルを生成します。

```powershell
python build.py
```

`build.py` はマーカーで Web 専用・オフライン専用部分を分け、NX専用版はNX生成UIとジャーナルコードを抽出して生成します。次のファイルを更新します。

- `index.html` — 広告枠とオフライン版のダウンロードリンクを含む Web 版
- `tolerance-tool-offline.html` — 外部通信を CSP で遮断した単一ファイル版
- `nx-journal-generator.html` — ジャーナル生成だけに絞った単一ファイル版
- `SHA256SUMS.txt` — オフライン版とNX専用版の SHA-256

生成ファイルを直接編集せず、変更後は `python build.py` を実行してください。
