# NX Automation Labs

簡易パラメトリック形状の作成、三角形メッシュの検査、片持ち梁の強度概算をブラウザー内で行う機械設計ワークベンチです。モデルや計算データをサーバーへ送信せず、外部ランタイムライブラリーも使用しません。

## 主な機能

- 拘束状態を表示する矩形/円の定義済みスケッチと、幅・高さ・穴径などの駆動寸法編集
- 穴付きプレート、角丸押し出し形状、円柱の作成。穴とスケッチコーナーRを指定して再生成
- CADブラウザー風のモデルツリー、コマンドタブ、寸法付きXYスケッチ表示、3D視点操作とフィーチャー履歴
- 押し出し再生成、360°回転、貫通穴、スケッチ角Rをコマンドから適用し、直前の形状を履歴から復元
- スケッチ、押し出し/回転、穴、角丸を表示するフィーチャー履歴の記録と過去形状への復元
- 複数部品の配置、固定/ Z軸回転/ Z方向スライド接続、選択部品のX方向直線パターン
- STL / OBJ メッシュの読込、複数モデル配置、STL / JSON プロジェクトの出力
- メッシュの外接寸法、表面積・体積の参考値、境界/非多様体エッジ、退化三角形の検査
- 関節・配置を反映した部品ごとの AABB（軸平行外接直方体）重なり候補の表示と JSON レポート保存
- パラメトリック形状を使った、梁理論による曲げ応力・先端たわみ・安全率の概算
- ミニ四駆風レーシングカーとDIYデスクを切替できるライブプレビュー。CADのスケッチ・押し出し・アセンブリを4段階で高速表示
- ミニ四駆サンプルはメタリック空力ボディ、スモークキャノピー、レッド5スポーク、ガイドローラー、駆動系を備え、下面ビューではカウルを一時非表示にしてシャーシ裏側を確認可能
- ワークベンチの初期モデルにミニ四駆風サンプルアセンブリを用意。シャーシ寸法と各部品の配置を編集可能

## 適用範囲と制約

本サイトは軽量なブラウザーワークベンチであり、汎用 CAD カーネルや設計承認用ツールではありません。

- 形状編集は定義済みの矩形/円プロファイルに限定されます。拘束表示はその寸法パラメーターに対するもので、任意の線・円弧を解く汎用スケッチソルバーではありません。角丸はスケッチ外周の近似押し出しで、B-rep エッジのフィレット/シェル/スイープ/ロフト等には対応していません。
- アセンブリ接続は部品原点のZ軸回転またはZ方向スライドを適用する簡易表示です。ジョイント解法、複数の拘束条件、接触追跡、アセンブリ運動学、構成管理は未実装です。直線パターンは選択部品の複製で、フィーチャーパターンではありません。
- 入出力は STL / OBJ 読込と STL / JSON 出力です。STEP / IGES、ネイティブ CAD 形式には対応していません。
- エッジ接続検査は三角形メッシュに対する簡易判定です。AABB の重なりは一次抽出候補であり、正確なソリッド干渉ではありません。単位情報のないメッシュ座標は mm として扱います。
- 強度値は矩形または円形断面に先端荷重が作用する Euler–Bernoulli 片持ち梁式の概算です。FEA や規格適合判定ではありません。穴による断面欠損と応力集中、せん断、座屈、疲労、接合部、実際の荷重分布は評価しません。材料値と前提を信頼できる資料で確認し、安全に関わる設計は専門家の検証を受けてください。
- 製品ページのアニメーションはブラウザー上のライブプレビューであり、収録動画ではありません。
- 製品ページのミニ四駆風モデルとデスクは、CAD工程を見せるライブプレビューです。ワークベンチには別途ミニ四駆風サンプルアセンブリを初期表示します。シャーシの寸法と部品の配置は編集できますが、ボディ等のメッシュ部品形状自体のフィーチャー編集には対応していません。

## ビルド

Python 3.10 以降が必要です。サードパーティー依存関係はありません。

```powershell
python build.py
```

次のファイルを生成します。

- `index.html` — オフライン専用 CSP を含まない Web ページ
- `cad-workbench-offline.html` — 制限的な CSP を持つ単一ファイル版
- `SHA256SUMS.txt` — オフライン版の SHA-256

ハッシュは次の PowerShell コマンドで確認できます。

```powershell
Get-FileHash .\cad-workbench-offline.html -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

## SolidCraft との位置づけ

SolidCraft は任意形状の拘束スケッチ、編集可能なフィーチャー、アセンブリ、CAD 交換形式など、より広い汎用 CAD 機能を提供します。本サイトは現時点でその代替をうたわず、定義済みスケッチと基本フィーチャー/簡易接続を、ローカル処理のメッシュ QA・干渉候補・強度の一次評価へつなぐ点を差別化方針とします。ライブプレビューは収録動画ではなく、ブラウザー上の段階的な描画です。正確な CAD カーネル操作、干渉判定、FEA は今後の課題であり、現状の機能としては扱いません。
